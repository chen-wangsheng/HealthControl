# 个人健康管理系统核心功能流程图

本文档详细描述系统15个核心功能的业务流程，通过流程图直观展示各功能的执行逻辑。

---

## 1. 用户注册流程

```
┌─────────────┐
│   开始      │
└──────┬──────┘
       ▼
┌─────────────┐
│ 填写注册信息 │

┌─────────────┐     否
│ 验证信息格式 │────────┐
└──────┬──────┘        │
       │是             ▼
       ▼         ┌──────────┐
┌─────────────┐  │ 提示错误  │
│ 检查账号是否 │  │ 重新填写  │
│   已存在    │  └──────────┘
└──────┬──────┘
       │
   ┌───┴───┐
```

用户注册是系统的入口功能。用户需填写账号、密码、手机号等基本信息，系统会验证信息格式的正确性，并检查账号是否已被注册。验证通过后，密码经MD5加密存储到数据库，完成注册后自动跳转到登录页面。

微信绑定功能实现账号与微信的关联。用户在小程序中点击绑定按钮，系统调用微信登录接口获取code，发送到后端换取OpenId。后端检查该OpenId是否已被其他账号绑定，若未绑定则保存关联关系。绑定成功后，用户下次可直接使用微信一键登录，无需输入账号密码。
