# 个人健康管理系统后端技术报告

## 一、项目概述

本项目是一个基于Spring Boot 3.3.1的个人健康管理系统后端服务，为用户提供健康数据记录、饮食管理、运动追踪、健康知识阅读以及AI智能健康分析等功能。系统采用前后端分离架构，后端提供RESTful API接口供前端调用。

## 四、核心功能模块

### 4.1 用户管理模块

提供完整的用户生命周期管理：

- 用户注册/登录（支持微信小程序登录）
- JWT Token认证
- 密码找回/修改/重置
- 微信绑定/解绑
- 用户信息管理与导出

### 4.2 健康指标管理模块

支持多种健康指标的记录与追踪：

| 指标分类 | 包含指标 |
|---------|---------|
| 血糖指标 | 空腹血糖、餐后2小时血糖、糖化血红蛋白 |
| 基础体征 | 身高、体重、体温、BMI指数 |
| 血压指标 | 收缩压、舒张压 |
| 血脂指标 | 总胆固醇、甘油三酯、低密度脂蛋白、高密度脂蛋白 |
| 心率指标 | 静息心率、运动心率 |
| 肝功能 | 谷丙转氨酶、谷草转氨酶、总胆红素 |
| 肾功能 | 血肌酐、血尿素氮、尿酸 |
| 血常规 | 白细胞、红细胞、血红蛋白、血小板 |
| 呼吸功能 | 肺活量、血氧饱和度 |

### 4.3 饮食管理模块

- 食物库管理（8大类：谷物、蔬菜、水果、肉类、蛋奶、豆类、坚果、饮品）
- 食物营养成分（热量、蛋白质、碳水化合物、脂肪）
- 饮食记录与统计
- 每日营养摄入分析

### 4.4 运动管理模块

- 运动项目管理
- 运动记录追踪
- 热量消耗计算
- 运动数据统计分析

### 4.5 健康知识模块

- 健康文章发布与管理
- 文章分类（营养饮食、运动健身、疾病预防、心理健康等8类）
- 文章审核机制
- 收藏/点赞功能

### 4.6 AI智能分析模块

集成DeepSeek大模型API，提供智能健康分析：

```java
// AI分析核心流程
1. 收集用户健康数据（指标、饮食、运动）
2. 构建分析提示词
3. 调用DeepSeek API
4. 解析返回的JSON结果
5. 返回结构化分析报告
```

分析结果包含：
- 整体健康评分（0-100分）
- 健康风险识别
- 营养摄入分析
- 运动情况评估
- 各项指标分析
- 个性化健康建议

## 六、安全机制

### 6.1 身份认证

采用JWT（JSON Web Token）进行身份认证：

- Token有效期：180天
- 签名算法：HMAC256
- 请求头携带：Authorization

### 6.2 拦截器配置

```java
// 拦截器排除路径
- /User/SignIn      # 登录
- /User/Register    # 注册
- /User/ForgetPassword  # 找回密码
- /File/**          # 文件访问
```

### 6.3 密码安全

- 密码采用MD5加密存储
- 支持邮箱验证码找回密码

## 七、第三方服务集成

### 7.1 微信小程序

- 通过微信code获取OpenId
- 支持微信账号绑定/解绑

### 7.2 邮件服务

- 使用QQ邮箱SMTP服务
- 支持验证码发送

### 7.3 DeepSeek AI

- API地址：https://api.deepseek.com/chat/completions
- 模型：deepseek-chat
- 支持模拟模式（开发调试用）

## 八、性能优化

### 8.1 缓存策略

使用Caffeine本地缓存：
- AI分析结果缓存1小时
- 缓存Key：用户ID + 分析天数

### 8.2 数据库优化

- 使用MyBatis-Plus简化CRUD操作
- 合理使用索引
- 分页查询避免全表扫描
