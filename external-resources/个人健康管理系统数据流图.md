## 十一、处理逻辑说明

### 11.1 用户登录处理（1.2）

```
输入：用户名、密码
输出：JWT Token 或 错误信息

处理逻辑：
1. 验证用户名和密码格式
2. 查询用户数据存储，获取用户信息
3. 比对密码（MD5加密后比对）
4. 如果验证通过：
   - 生成JWT Token（包含用户ID、角色、过期时间）
   - 返回Token给用户
5. 如果验证失败：
   - 返回错误信息
```

### 11.2 健康指标异常判断（2.5）

```
输入：指标ID、记录值
输出：是否异常标记

处理逻辑：
1. 根据指标ID查询指标阈值范围
2. 解析阈值格式（如"60-100"）
3. 判断记录值是否在阈值范围内
4. 如果超出范围：
   - 标记为异常（IsAbnormity='Y'）
   - 可触发消息通知
5. 如果在范围内：
   - 标记为正常（IsAbnormity='N'）
```

### 11.3 AI分析处理（6.0）

```
输入：用户ID、分析天数
输出：健康分析报告

处理逻辑：
1. 获取用户基本信息（年龄、性别等）
2. 收集指定天数内的健康数据：
   - 健康指标记录
   - 饮食记录（计算热量摄入）
   - 运动记录（计算热量消耗）
3. 格式化数据为JSON结构
4. 构建AI提示词（包含分析要求）
5. 调用DeepSeek API
6. 解析AI返回的分析结果
7. 返回结构化的分析报告
```

### 11.4 热量计算处理（3.5/4.4）

```
饮食热量计算：
输入：食物ID、单位ID、数量
输出：总热量（kcal）

处理逻辑：
1. 查询食物营养信息（热量/100g）
2. 查询单位换算值（克数）
3. 计算：总热量 = 热量/100g × 单位克数/100 × 数量

运动热量计算：
输入：运动ID、单位ID、运动量
输出：消耗热量（kcal）

处理逻辑：
1. 查询运动单位信息（热量值/单位）
2. 计算：消耗热量 = 单位热量值 × 运动量
```
